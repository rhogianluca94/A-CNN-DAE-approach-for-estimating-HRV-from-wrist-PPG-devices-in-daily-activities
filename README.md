# A-CNN-DAE-approach-for-estimating-HRV-from-wrist-PPG-devices-in-daily-activities
We publicly share a methodology based on an ensemble of convolutional denoising autoencoders (CNN-DAEs) to denoise PPG time series under high-intensity activity, followed by a PRV tracking algorithm designed to improve the reliability of pulse rate variability (PRV) time-domain parameters (meanHR, stdRR, RMSSD).
